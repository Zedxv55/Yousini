# Skill: การเขียนเทสต์ (ตัวอย่าง)

สกิลนี้สาธิตโครงสร้าง `skills/*.md` — ทุกไฟล์ `.md` ในโฟลเดอร์ `skills/`
จะถูกโหลดเข้า system prompt อัตโนมัติเมื่อเริ่มงาน

## เมื่อผู้ใช้ขอให้เขียนเทสต์

1. หาไฟล์ที่จะเทสต์ผ่าน `glob` (`*.py`)
2. สร้างไฟล์เทสต์คู่ข้างเคียง (`test_<module>.py`)
3. ใช้ `pytest` เป็น framework หลัก
4. ครอบฟังก์ชันที่ต้อง mock ด้วย `unittest.mock`
5. รัน `pytest -q` ผ่าน `shell` แล้วตรวจผลก่อนสรุป

## ตัวอย่าง

```python
def test_add():
    assert add(1, 2) == 3
```
